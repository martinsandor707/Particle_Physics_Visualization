Ingest a calorimeter file — CSV or Parquet — into an isolated experiment table, from this computer or from a file already on the server. Three schemas are accepted: the two-shower all-models inference file (hits_all_models), the single-shower hit file (standalone_hits) and the single-shower event-level aggregate (standalone_events).
Lowercase letters, digits and underscores; must start with a letter.
